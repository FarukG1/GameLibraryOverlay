# Input prompt artwork

The PNG files in `src/GameLibrary.App/Assets/Input` are from **Kenney Input Prompts 1.1**, created by Kenney, licensed under CC0.

- Original artist: https://kenney.nl/assets/input-prompts
- Source repository: https://github.com/tanuki-billie/kenney-input-prompts
- Pinned source revision: `49f37cc4e74fa661382f9752567924a8109b6568`
- Original license notice: `src/GameLibrary.App/Assets/Input/LICENSE.txt`

Only Xbox A/B/X/Y and keyboard letters, numbers, F1–F12, modifiers, and Escape PNGs are included. Images are embedded locally; the app does not download artwork or load the upstream Godot plugin at runtime.
